# Несколько ракурсов каждого объекта

Новый набор взамен прежних одиночных фотографий. Объекты заменены на те, для которых найдены настоящие согласованные серии. В каждой папке — один и тот же физический объект. Новые ракурсы не синтезировались; зеркальные копии не использовались.

| Объект | Ракурсы | Разрешение | Источник |
|---|---:|---|---|
| Уточка | 12, через 30° по кругу | 128 × 128 | COIL-100, объект 74 |
| Кот манэки-нэко | 12, через 30° по кругу | 128 × 128 | COIL-100, объект 14 |
| Лягушка | 12, через 30° по кругу | 128 × 128 | COIL-100, объект 28 |
| Игрушечный леопард | 8 | исходное, см. sources.json | ETHZ Toys, LEO1–LEO8 |
| Шестерня | 12 кадров разных положений | исходное, см. sources.json | VGM-6D, gear0001 |
| Гайка | 12 кадров разных положений | исходное, см. sources.json | VGM-6D, nut0001 |

Всего 68 основных изображений. TIFF-оригиналы леопарда дополнительно сохранены в original_tiff; PNG — преобразование формата без обрезки, ретуши и изменения ракурса.

## Ограничения для эксперимента

- COIL-100 имеет небольшое исходное разрешение: пригоден для проверки формы и многовидового конвейера, но не тонких деталей. Ракурсы меняются по азимуту, высота камеры фиксирована; видов снизу нет.
- Леопард — мягкая игрушка с кольцом и ярлычком, которые видны в некоторых видах. Изображения согласованной серии, но углы авторами не указаны.
- VGM-6D показывает детали на зелёной платформе, иногда рядом руки и маркеры. Для генерации именно детали требуется выделение объекта; файлы здесь сохранены без изменения. Это повороты/наклоны в пределах записанной траектории, не обещание полного обзора 360°. Индексы кадров не являются градусами.
- Для VGM-6D сохранены CSV поз и XCP из исходных архивов. Не следует трактовать столбцы углов как готовые параметры камеры Blender без проверки системы координат.
- Выборка VGM-6D распределена по всей последовательности; это не отбор гарантированно равномерных ракурсов.
