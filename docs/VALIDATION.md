# Проверка первой версии

Дата: 21 октября 2026. Компьютер: i7-12650H, 16 ГБ RAM, RTX 4070 Laptop 8188 MiB.

Реальный запуск: `8a70425d2fba`. [Открыть результат](http://127.0.0.1:7860/?run=8a70425d2fba). Пять фотографий одной уточки COIL-100; SF3D получил ракурс 300°, четыре остальных — проверочные.

| Этап | Проверка | Измерение |
|---|---|---|
| SF3D | Настоящая генерация GLB по фотографии | 6167 MiB allocated VRAM |
| EEVEE | По 36 настоящих рендеров до/после, 384×384 | Фиксированные камеры |
| Qwen3-VL-4B | Настоящая критика до/после, NF4 | 3030 MiB allocated VRAM на повторной оценке |
| TextDeformer | 150 настоящих шагов на сетке 12 000 граней | 23.7 с, 1945 MiB allocated VRAM |
| Регрессии | API, маски, камеры, компоненты, откат, JSON критика | 16 тестов прошли |

Средний IoU всех пяти видов: **78.66% → 78.62%**. Правка **отклонена**. Средний IoU проверочных видов вырос примерно на 0.67 процентного пункта, но худший проверочный вид ухудшился примерно на 4.03 пункта (допуск — 3 пункта). Повторный критик также указал на возможное несогласование камеры.

`best.glb` сохранил исходную геометрию — проверено численно с допуском 1e-6. Кандидат остался в `iteration_01`, его можно изучить отдельно. Этот пример подтверждает работу конвейера и отката, **не гарантирует улучшение качества**.

Во время разработки был уточнён формат ответа критика, а исходное описание CLIP зафиксировано по параметрам запуска. Первоначальный ответ критика сохранён в `iteration_00/critique.json.initial` и `raw_response.txt.initial`; повторная оценка отражена в событиях запуска.

Числа по видеопамяти — allocated VRAM PyTorch в измеряемом этапе, без полной памяти драйвера. Метрика силуэта использует приблизительные камеры и нормировку масштаба/сдвига. Это не оценка инженерной точности или ошибки поверхности 3D.

Подробные числа: `validation.json`. Состояние среды: `logs/doctor.json`.
