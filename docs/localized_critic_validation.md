# Проверка локализованного критика и редактора

Проверено на компьютере проекта 24 октября 2026 года.

- Регрессионные тесты проверяют все фото в задании критика, соответствие плана
  типу замечания, неподтверждённые области, z-buffer и закрытые поверхности,
  действительное удаление граней, ограниченную локальную деформацию, очистку без
  заполнения отверстий, откат при отрицательной VLM-проверке даже при росте IoU,
  сопоставление top/bottom и доступность материалов новых этапов.
- Реальный Blender EEVEE: шесть осевых видов асимметрично расположенной тестовой
  сетки, 192×192. Силуэт CPU z-buffer по сохранённым матрицам совпал с альфой
  Blender с IoU 0.99907–0.99987. Артефакты: `runs/_localized_smoke/`.
- Реальная Qwen3-VL-4B-Instruct NF4: две пары из сохранённого запуска лягушки,
  затем объединение в план. Пиковая память PyTorch около 3256 МБ. При неверном
  формате операции выполнен повторный запрос; модель выбрала отсутствие
  исполнимой операции из-за несогласованных локальных наблюдений. Непроверенная
  операция не подставлялась автоматически. Артефакты: `runs/_critic_v2_smoke/`.
- Реальная независимая проверка Qwen на двух парах с одинаковыми BEFORE/AFTER:
  оба вида получили `improved=false`, кандидат отклонён. Артефакты:
  `runs/_critic_v2_verify_smoke/`.
- Интерфейс проверен в браузере: все семь сравнений сохранённого запуска и список
  этапов отображаются. Сервер обновлён после завершения пользовательского запуска.

Это проверка исполнения протокола и защит от неверных правок, не доказательство
роста точности реконструкции на всём наборе. Повторная генерация с новым seed
не гарантирует устранения конкретного дефекта. Автоматическая оценка VLM остаётся
ошибочной в отдельных случаях; локализация прямоугольниками приблизительная.
Дифференцируемая подгонка по фото и сравнение 4B/8B в эту версию не входят.
