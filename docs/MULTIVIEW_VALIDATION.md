# Многовидовая реконструкция и просмотр этапов

Проверено 21 октября 2026 на RTX 4070 Laptop 8 ГБ. Веса SF3D и Qwen прежние; дополнительно установлен scikit-image 0.25.2 в базовое venv для marching cubes. Все запуски и рендеры настоящие.

## Что изменено

Для COIL-серий с известными относительными азимутами режим «Авто» теперь использует отдельную многовидовую реконструкцию внешнего объёма. SF3D остаётся сохранённым исходным вариантом. Используются 9 из 12 выбранных фото; три распределённых по кругу фото не участвуют в построении или выборе камеры. Пространственное поле получается пересечением интерполированных знаковых расстояний до силуэтов; marching cubes и сглаживание уменьшают ступенчатость. Модель не растягивается по одной оси.

Приближённая ортографическая камера, центрирование по ограничивающей рамке и масштабирование по высоте не являются полной калибровкой. У COIL изображения нормированы; метод пригоден для грубого объёма, а не для точных размеров. При неизвестных углах остаётся SF3D: индексы файлов не используются как углы.

Обе сетки замкнуты и состоят из одного связного компонента. Исходные плоские SF3D-сетки сохранены, можно сравнить их с реконструкциями в интерфейсе. Это подтверждает появление внешнего объёма, но **не доказывает точного восстановления 3D**. Невысокий F1 показывает, что контуры всё ещё заметно расходятся, несмотря на относительно высокий IoU.

Все измерения: [multiview-validation.json](multiview-validation.json). Размеры — относительные единицы, не миллиметры.

## VLM остаётся ограничением

Qwen3-VL-4B даже после добавления независимых видов и уточнения инструкции продолжает указывать на плоскостность этих объёмных сеток. Эти ответы сохранены без подмены. У кошки также сохранён предыдущий ответ до повторной оценки с суффиксом `before_prompt_review`. Численные измерения и VLM дают противоречивую оценку; интерфейс явно показывает это и не запускает автоматическую деформацию по такому заключению. Наличие глобальной толщины не исключает локального уплощения, шероховатости и ошибок формы.

Visual hull не восстанавливает невидимые по контурам впадины, скульптурные детали лица и PBR-материалы. Результат остаётся грубой реконструкцией по фотографиям 128×128. Нет эталонной 3D-модели, поэтому ошибка поверхности 3D и точность скрытых сторон не измерены.

## Этапы и проверки

В интерфейсе доступны входные фото/параметры, SF3D-кандидаты, многовидовая реконструкция, рендеры и метрики, исходные ответы и запрос критика, TextDeformer существующих итераций. Можно переключать GLB/OBJ, просматривать геометрию, скачивать исходник, открывать все пары фото/рендеров, JSON и журнал. Сопоставления показываются только для того файла модели, для которого они вычислены. Просмотр нормирует размер и при необходимости упрощает копию до 20 000 граней; исходный файл сохраняется.

32 теста прошли: контуры, замкнутая многовидовая геометрия, отдельные проверочные фото, исключение проверочных фото из согласования камеры, дополнительные критерии принятия, сохранение исходного SF3D, API этапов, GLB-просмотр и изоляция файлов. GPU-границы в тесте оркестрации явно подменены; реальные проверки описаны выше.
